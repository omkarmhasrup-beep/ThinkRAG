Google Gemini API Documentation
Official Guide to GenAI SDK Client, Content Generation, and Streaming

1. Google GenAI SDK Client
The official `google-genai` Python SDK provides direct interaction with Google Gemini models (`gemini-3.6-flash`, `gemini-2.5-pro`, `gemini-embedding-001`) via `genai.Client(api_key=...)`.

from google import genai
import os
client = genai.Client(api_key=os.getenv("GOOGLE_API_KEY"))
response = client.models.generate_content(
model="gemini-3.6-flash",
contents="Explain quantum computing in one short paragraph."
)
print("Response:", response.text)

2. Real-Time Streaming & Embeddings
Gemini API supports real-time token streaming via `generate_content_stream` and vector embeddings generation via `embed_content`.

# Token Streaming
stream_resp = client.models.generate_content_stream(
model="gemini-3.6-flash",
contents="List 3 key benefits of Python."
)
for chunk in stream_resp:
if chunk.text:
print(chunk.text, end="", flush=True)
